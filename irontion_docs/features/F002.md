# F002: Activity Feature

Users can create their own activities and assign them to time blocks from [[F001]]. Each activity can contain nested sub-activities and can have tags, so users can organize and filter their time in any way they like.

> [!info] Activity Overview
> - Activities are **created by the user** (no fixed list)
> - Each activity has a **name** and a **color**
> - Each activity can contain **nested sub-activities**
> - Each activity can have **tags** for grouping and filtering
> - Activities are assigned to cells in the Blocos grid (10 minutes per cell)

## Activity Structure

| Field            | Description                                        |
| ---------------- | -------------------------------------------------- |
| `id`             | Unique identifier                                  |
| `name`           | Activity name (e.g., "Schedule", "Drawing")        |
| `color`          | Color used to fill cells in the grid               |
| `parent_id`      | `null` for top-level activity, otherwise parent ID |
| `sub_activities` | List of child activities (nested)                  |
| `tags`           | List of tags attached to this activity             |

## Tag System

Tags are labels that cut across the activity tree. They let users group activities that are in different places in the hierarchy.

- A tag has a **name** (required) and an optional **color**
- One activity can have **multiple tags**
- One tag can be used by **many activities**
- Tags are created by the user and can be reused
- Users can filter the summary by tag (Insights page)
- **Notes use the same tags** ([[F006]]): typing `#name` in a note reuses a tag with that name (ignoring case) or creates one. A note can carry up to 5. Tags created from a note may only use letters, combining marks and digits in any script, `_` and `-`
- Note tags never change the time summaries: notes are not time data

| Field   | Description                         |
| ------- | ----------------------------------- |
| `id`    | Unique identifier                   |
| `name`  | Tag name (e.g., "deep-work")        |
| `color` | Optional tag color                  |

### Tag Examples

- `deep-work`: needs full focus
- `low-energy`: can be done when tired
- `health`: exercise, sleep, meals
- `creative`: drawing, writing, design
- `online`: needs a computer or internet

## Examples

### Example 1: Eisenhower Matrix (4Q technique)

Top-level activities are the four quadrants.

- **Urgent** (red)
  - Fix a bug before deadline `#deep-work`
  - Pay a bill that is due today
- **Schedule** (blue)
  - Read a book `#low-energy`
  - Plan next week `#online`
  - Exercise `#health`
- **Delegate** (orange)
  - Reply to routine emails `#online`
  - Ask a teammate to prepare a report
- **Don't do** (gray)
  - Scroll social media
  - Watch random videos

### Example 2: Student Daily Routine

- **Study** (purple)
  - Math homework `#deep-work`
  - Review lecture notes `#low-energy`
  - Language practice `#online`
- **Health** (green)
  - Sleep `#health`
  - Morning run `#health`
  - Cook meals `#health`
- **Rest** (yellow)
  - Gaming
  - Hang out with friends

### Example 3: Freelance Artist

- **Drawing** (pink)
  - OC artwork `#creative` `#deep-work`
  - Drawing practice `#creative` `#low-energy`
- **Client Work** (blue)
  - Commission sketch `#creative` `#deep-work`
  - Reply to clients `#online`
  - Send invoice `#online`
- **Life** (green)
  - Exercise `#health`
  - Meals `#health`

> [!note]
> The structure is fully free-form. Users decide the names, the depth, the colors, and the tags.

## Behavior

- [x] User can create a new activity (name + color)
- [x] User can edit and delete an activity (delete = archive, see Decisions)
- [x] User can add sub-activities inside any activity
- [x] Sub-activities can be nested multiple levels deep (up to 5)
- [x] Sub-activity inherits the parent color by default (user can override)
- [x] User can add, remove, and create tags on an activity
- [x] User can rename or delete a tag (updates all activities and notes using it; deleting keeps the activities and notes)
- [x] The tags panel shows how many activities and notes use each tag
- [x] User selects an activity or sub-activity, then fills cells in the Blocos grid
- [x] Summary shows total blocks per activity, including the sum of its sub-activities
- [x] Summary can be filtered or grouped by tag (Insights page)
- [x] User can collapse and expand the activity tree (remembered)
- [x] Archived activities can be restored, or deleted forever with a warning
- [x] "Select an activity" list when allocating blocks: groups are headings, only leaf activities can be picked
- [x] Create an activity (or a sub-activity) straight from that list; it is allocated to the selection right away
- [x] Suggestions in the create form: starter names (Work, Morning routine, ...) that are not already used
- [ ] Reorder activities and move them to another parent (drag and drop)
- [x] Starter templates: 67 built-in templates in nine groups, with search and category filter, including the examples above (see [[F005]])
- [x] Delete everything at once (all activities, or just the time blocks) from Settings, Danger zone (see [[F003]])
- [ ] Filter the Blocks grid by tag

## Decisions

| Question | Decision |
| -------- | -------- |
| Maximum nesting depth? | **5 levels** (top-level = 1) |
| What happens to assigned cells when an activity is deleted? | **Archive, keep history.** "Delete" archives the activity and its sub-activities: they leave the tree and the picker, but past blocks and summaries keep them. From the Archived list they can be **restored** (brings back archived parents too) or **deleted forever** (removes blocks; the dialog shows how many). |
| Parent or sub-activity in cells? | **Only leaf activities** (no active sub-activities) fill new cells. Parents act as groups. If a parent already had blocks before it got its first sub-activity, those blocks stay and still count; the form warns about this. |
| Do sub-activities inherit tags? | **Yes, for filtering and grouping.** Effective tags = own tags + all ancestors' tags. |
| Nested tags (`work/meeting`)? | **No** for now. Tags are flat. |
| Can the user wipe their activities? | **Yes, on purpose, from Settings.** Danger zone → Advanced → Delete data → *All activities* permanently removes every activity (archived ones too) **and all their time blocks**. It shows exact counts and needs a confirmation tick. Tags are kept. This is separate from the everyday "Delete" above, which only archives ([[F003]], Danger Zone). |
