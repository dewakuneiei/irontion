# F003: Theme (Light, Dark, System)

Users can choose how Irontion looks: a light theme, a dark theme, or follow the operating system automatically.

> [!info] Theme Overview
> - Three modes: **System** (default), **Light**, **Dark**
> - **System** follows the OS setting and switches live when the OS changes
> - The choice is saved and restored on the next launch
> - The window title bar matches the chosen theme

## Modes

| Mode       | Behavior                                                         |
| ---------- | ---------------------------------------------------------------- |
| **System** | Uses the OS preference (GNOME / KDE on Linux, Windows, macOS)    |
| **Light**  | Always light, even if the OS is dark                             |
| **Dark**   | Always dark, even if the OS is light                             |

## Where to Change It

**Settings only.** (The quick switch that used to sit at the bottom of the sidebar was removed.)

- **Settings → Appearance:** three cards (System, Light, Dark) with a small preview of each
- **Settings → Accent color:** the app's highlight color, see below
- **Settings → Block shape:** squares or circles, see below
- **Settings → Time fill:** which way the current block fills, see below
- **Settings → Date and time:** date format, first day of the week, 12- or 24-hour time, see below

## Behavior

- [x] Default mode is **System**
- [x] Switching theme cross-fades the colors smoothly (no hard flash)
- [x] The saved theme is applied before the first paint (no flash of the wrong theme on startup)
- [x] In System mode, the app updates live when the OS theme changes
- [x] Native window title bar follows the theme (Tauri `setTheme`)
- [x] Charts use their own color steps for dark mode (not just inverted colors)
- [x] Settings shows the detected OS theme while in System mode
- [x] Every page supports all three modes: Today, Blocks, Activities, Insights, Settings, and all dialogs
- [ ] Respect "reduce motion": no cross-fade or slide animations (CSS done, verify on GNOME)
- [ ] Move the saved choice from `localStorage` into the SQLite settings table
- [x] Accent color is a setting: 7 presets plus any custom color
- [x] Block shape is a setting: square or circle
- [ ] Optional: high-contrast theme

## Accent Color

The default is the original sky blue. The user can pick another preset or any custom color in Settings. It changes buttons, active items, selection highlights, focus rings and the chart ramp (the heatmap).

| Preset | Light | Dark |
| ------ | ----- | ---- |
| Blue (default) | `#2a78d6` | `#3987e5` |
| Violet | `#6a4ee0` | `#8f7cf0` |
| Teal | `#0b7f72` | `#2dbfa9` |
| Green | `#2a7d3a` | `#4cc16a` |
| Orange | `#b84e0a` | `#f0893a` |
| Rose | `#c8326b` | `#ee6a9b` |
| Graphite | `#3f4652` | `#aab2bf` |

- Each preset has its own step per theme, both checked to read as text on that theme's surface.
- **Text on the accent** (button labels) is white unless that would be hard to read, then black. Dark-theme accents are lighter, so most use black text.
- **Custom colors** are adjusted automatically: lightened a little in dark mode, and nudged darker or lighter until they reach contrast 4.5 on the surface. A very light yellow becomes a readable olive instead of an unreadable button.
- The choice is applied before the first paint, so there is no flash of blue on startup.
- Components never assume blue: use `bg-accent`, `text-accent`, `bg-accent-soft`, `text-accent-ink`.

## Block Shape

A setting for the Blocks grid ([[F001]]): **square** (rounded square, default) or **circle**. Blocks are always the same width and height. It is a CSS variable (`--cell-radius`), so any future block-like element can follow it.

## Time Fill

The setting is called **Time fill**. It chooses the direction the current block fills as its ten minutes pass ([[F001]], Time Fill).

| Option | Fills |
| ------ | ----- |
| **Left to right** (default) | From the left edge to the right, matching how the grid reads time |
| Right to left | From the right edge |
| Bottom to top | From the bottom edge upward |
| Top to bottom | From the top edge downward |

Each option shows a half-filled sample in the current block shape (square or circle). The grid reads the choice from `preferences.fillDirection`.

## Date and Time

| Setting | Options | Default |
| ------- | ------- | ------- |
| Date format | Follow the language, DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD, DD.MM.YYYY, DD-MM-YYYY, YYYY/MM/DD, D MMM YYYY, MMM D, YYYY | Follow the language |
| Week starts on | **Any day**: Monday to Sunday | Monday |
| Time format | 24-hour (14:30), 12-hour (2:30 PM) | 24-hour |

- **Date format** and **Week starts on** are dropdowns (keyboard: arrows, Home, End, Enter, Esc). Each date format shows today's date as a live example next to its pattern.
- Settings saved by the earlier version ("monday" / "sunday") still load.
- **Follow the language** uses the language's own short date (Thai uses the Buddhist year). The fixed formats always use Gregorian years; month names (D MMM YYYY) stay in the app language.
- Used by: the Blocks date button and calendar, the Today header, heatmap tooltips, the grid's hour rows, selected cells and the selection time span.
- Week start changes the calendar and the heatmap rows.
- In 12-hour time the grid rows read "8 AM"; selected cells show a short "8:10" because the row already says AM or PM.

## Design Tokens

All colors are CSS variables on `:root`, switched by `<html data-theme="light|dark">`.

| Token          | Light     | Dark      | Used for                    |
| -------------- | --------- | --------- | --------------------------- |
| `--bg`         | `#f4f4f1` | `#0d0d0d` | Page background             |
| `--surface`    | `#fcfcfb` | `#1a1a19` | Cards, sidebar              |
| `--surface-2`  | `#f0efec` | `#232322` | Inputs, segmented controls  |
| `--text`       | `#0b0b0b` | `#ffffff` | Primary text                |
| `--text-2`     | `#52514e` | `#c3c2b7` | Secondary text              |
| `--muted`      | `#898781` | `#898781` | Hints, axis labels          |
| `--accent`     | user's accent (blue by default) | user's accent | Active items, focus ring, buttons |
| `--accent-soft`| accent at 12% | accent at 16% | Selected items, chips |
| `--accent-ink` | white or black | white or black | Text on the accent |
| `--cell-radius`| `0.75rem` or `50%` | same | Block shape |
| `--danger`     | `#d03b3b` | `#e66767` | Destructive actions, errors |

> [!note]
> Activity colors (from [[F002]]) are chosen by the user and stay the same in both themes. Text drawn on an activity color picks black or white automatically for contrast (`readableInk`). The Blocos grid in [[F001]] is tested in both modes.

## Implementation

- `apps/desktop/src/lib/theme.svelte.ts`: theme state, OS detection, persistence
- `apps/desktop/src/lib/preferences.svelte.ts`: accent color and block shape
- `apps/desktop/src/lib/domain/accent.ts`: presets, custom-color adjustment, chart ramp (unit-tested)
- `apps/desktop/src/lib/components/settings/`: the accent, shape, time fill and date and time settings
- `apps/desktop/src/lib/components/Select.svelte`: the themed dropdown
- `apps/desktop/src/lib/domain/datetime.ts`: date formats, clock, calendar grid (unit-tested)
- `apps/desktop/src/lib/format.svelte.ts`: display helpers that apply the user's choices
- `apps/desktop/src/app.css`: color tokens for both themes
- `apps/desktop/src/lib/charts/palette.ts`: chart colors per theme
