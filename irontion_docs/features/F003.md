# F003: Theme and Settings

The Settings page: how Irontion looks (light, dark or follow the operating system, accent color, block shape, time fill), how dates and times read, the language, and a Danger zone for deleting data. The first half of this spec is the theme, which gave the feature its number.

> [!info] Theme Overview
> - Three modes: **System** (default), **Light**, **Dark**
> - **System** follows the OS setting and switches live when the OS changes
> - The choice is saved and restored on the next launch
> - The window title bar matches the chosen theme
> - Settings cards, top to bottom: Appearance, Accent color, Block shape, Time fill, **Animations**, **Note paper**, Date and time, Language, **Danger zone**, About

## Modes

| Mode       | Behavior                                                         |
| ---------- | ---------------------------------------------------------------- |
| **System** | Uses the OS preference (GNOME / KDE on Linux, Windows, macOS)    |
| **Light**  | Always light, even if the OS is dark                             |
| **Dark**   | Always dark, even if the OS is light                             |

## Where to Change It

**Settings only.** (The quick switch that used to sit at the bottom of the sidebar was removed.)

- **Settings → Appearance:** three cards (System, Light, Dark) with a small preview of each
- **Settings → Accent color:** the app's highlight color, see below
- **Settings → Block shape:** squares or circles, see below
- **Settings → Time fill:** which way the current block fills, see below
- **Settings → Animations:** play animations (all motion) and the water wave, see below
- **Settings → Note paper:** lined or plain paper for sticky notes, see below
- **Settings → Date and time:** date format, first day of the week, 12- or 24-hour time, see below
- **Settings → Language:** System default or one of the five languages, see below
- **Settings → Danger zone:** delete data behind an Advanced fold-out, see below
- **Settings → About:** version, tagline and the credit line, see below

## Accent Color

The default is the original sky blue. The user can pick another preset or any custom color in Settings. It changes buttons, active items, selection highlights, focus rings and the chart ramp (the heatmap).

| Preset | Light | Dark |
| ------ | ----- | ---- |
| Blue (default) | `#2a78d6` | `#3987e5` |
| Violet | `#6a4ee0` | `#8f7cf0` |
| Teal | `#0b7f72` | `#2dbfa9` |
| Green | `#2a7d3a` | `#4cc16a` |
| Orange | `#b84e0a` | `#f0893a` |
| Rose | `#c8326b` | `#ee6a9b` |
| Graphite | `#3f4652` | `#aab2bf` |

- Each preset has its own step per theme, both checked to read as text on that theme's surface.
- **Text on the accent** (button labels) is white unless that would be hard to read, then black. Dark-theme accents are lighter, so most use black text.
- **Custom colors** are adjusted automatically: lightened a little in dark mode, and nudged darker or lighter until they reach contrast 4.5 on the surface. A very light yellow becomes a readable olive instead of an unreadable button.
- The choice is applied before the first paint, so there is no flash of blue on startup.
- Components never assume blue: use `bg-accent`, `text-accent`, `bg-accent-soft`, `text-accent-ink`.

## Block Shape

A setting for the Blocks grid ([[F001]]): **square** (rounded square, default) or **circle**. Blocks are always the same width and height. It is a CSS variable (`--cell-radius`), so any future block-like element can follow it.

## Time Fill

The setting is called **Time fill**. It chooses the direction the current block fills as its ten minutes pass ([[F001]], Time Fill).

| Option | Fills |
| ------ | ----- |
| **Left to right** (default) | From the left edge to the right, matching how the grid reads time |
| Right to left | From the right edge |
| Bottom to top | From the bottom edge upward |
| Top to bottom | From the top edge downward |

The **water wave** switch lives in Settings → Animations (on by default). The wave is a soft moving ripple on the surface of the filling block. Only the current block animates, it pauses when the window is hidden, and it respects "reduce motion" ([[F001]], Time Fill).

Each option shows a half-filled sample in the current block shape (square or circle). The grid reads the choice from `preferences.fillDirection`.

## Note Paper

How sticky notes ([[F006]]) look: **Lined** (default), with ruled lines and a red margin line, or **Plain**. Each option shows a sample drawn with the real paper style. The choice is saved in `localStorage` and set as `<html data-note-paper>`. The paper's colors are theme tokens (`--note`, `--paper-*`), so they follow light and dark.

## Animations

Two switches. **Play animations** (on by default) turns all motion on or off: page and card entrances, fades, the notes board's slide and glide, the water wave. It sets `<html data-animations="off">`, and `app.css` then removes every CSS animation and transition; code-driven motion (the board) checks `preferences.motion`, which is also false when the OS asks for reduced motion. The **water wave** switch (the wave on the filling block, [[F001]]) is its own choice. The choices are saved in `localStorage` and applied before the first paint.

## Date and Time

| Setting | Options | Default |
| ------- | ------- | ------- |
| Date format | Follow the language, DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD, DD.MM.YYYY, DD-MM-YYYY, YYYY/MM/DD, D MMM YYYY, MMM D, YYYY | Follow the language |
| Week starts on | **Any day**: Monday to Sunday | Monday |
| Time format | 24-hour (14:30), 12-hour (2:30 PM) | 24-hour |

- **Date format** and **Week starts on** are dropdowns (keyboard: arrows, Home, End, Enter, Esc). Each date format shows today's date as a live example next to its pattern.
- Settings saved by the earlier version ("monday" / "sunday") still load.
- **Follow the language** uses the language's own short date (Thai uses the Buddhist year). The fixed formats always use Gregorian years; month names (D MMM YYYY) stay in the app language.
- The date picker opens as its own dialog, so it is never clipped inside another dialog or container.
- Used by: the Blocks date button and calendar, the Today header, heatmap tooltips, the grid's hour rows, selected cells and the selection time span.
- Week start changes the calendar and the heatmap rows.
- In 12-hour time the grid rows read "8 AM"; selected cells show a short "8:10" because the row already says AM or PM.

## Danger Zone

The last card before About. It is built for **accident prevention**: nothing destructive is on screen until the user opens it.

1. The card shows only its title and an **Advanced** button (`aria-expanded`). Pressing it folds out the options; pressing it again folds them away. Future danger options (for example "Reset settings") go inside the same fold-out.
2. **Delete data…** opens a dialog with four choices, defaulting to the smallest:

| Choice | Removes | Keeps |
| ------ | ------- | ----- |
| **Time blocks in a date range** (default) | Blocks from *From* to *To*, both days included. A single day: pick the same date twice | Activities, tags, other days |
| **All time blocks** | Every block on every day | Activities, tags |
| **All activities** | Every activity, archived ones too, and with them **all their blocks** | Tags, notes |
| **All notes** | Every note ([[F006]]), with its tag links | Time blocks, activities, **tags** |

3. The dialog shows **exactly how much will go** ("Time blocks to delete: 61", for activities also "Activities to delete: 11", for notes "Notes to delete: 7"), recounted whenever the choice or dates change. When there is nothing to delete it says so.
4. **Delete** stays disabled until the user ticks **I understand this can't be undone**. Ticking resets whenever the choice changes.
5. A backwards range ("From" after "To") shows an error and cannot be deleted.
6. On success the dialog closes, a "Data deleted." notice shows, and the Blocks, Today and Insights pages refresh (activities reload and the open day is reopened), and after deleting notes the Notes page and the Calendar refresh too.
7. **Deleting activities or time blocks never deletes notes**, and deleting notes never touches activities or blocks. The confirmation rules are the same for every choice.

- One transaction: all or nothing. Rust is the authority on the rules; the browser preview backend follows them.
- Activities removed this way are **permanently deleted**, unlike "Delete" on the Activities page which archives first ([[F002]]).

## Language

Three kinds of rows: **System default** (shows the detected language), then English, ไทย, 简体中文, 日本語 and 한국어, each written in its own language. The app follows the OS language unless one is picked. Every visible string exists in all five ([[F005]] explains what stays as the user typed it).

## About

Shows the logo, the version, the tagline and a credit line: "Created by dewakuneiei (https://github.com/dewakuneiei) · https://github.com/dewakuneiei/irontion". The project is under the Apache License 2.0 (`LICENSE`), and the `NOTICE` file asks everyone who uses Irontion to keep that credit. The credit is plain text for now; making the links clickable needs an opener in `src/lib/api/`.

## Design Tokens

All colors are CSS variables on `:root`, switched by `<html data-theme="light|dark">`.

| Token          | Light     | Dark      | Used for                    |
| -------------- | --------- | --------- | --------------------------- |
| `--bg`         | `#f4f4f1` | `#0d0d0d` | Page background             |
| `--surface`    | `#fcfcfb` | `#1a1a19` | Cards, sidebar              |
| `--surface-2`  | `#f0efec` | `#232322` | Inputs, segmented controls  |
| `--text`       | `#0b0b0b` | `#ffffff` | Primary text                |
| `--text-2`     | `#52514e` | `#c3c2b7` | Secondary text              |
| `--muted`      | `#898781` | `#898781` | Hints, axis labels          |
| `--accent`     | user's accent (blue by default) | user's accent | Active items, focus ring, buttons |
| `--accent-soft`| accent at 12% | accent at 16% | Selected items, chips |
| `--accent-ink` | white or black | white or black | Text on the accent |
| `--cell-radius`| `0.75rem` or `50%` | same | Block shape |
| `--danger`     | `#d03b3b` | `#e66767` | Destructive actions, errors |

> [!note]
> Activity colors (from [[F002]]) are chosen by the user and stay the same in both themes. Text drawn on an activity color picks black or white automatically for contrast (`readableInk`). The Blocos grid in [[F001]] is tested in both modes.

## Implementation

- `apps/desktop/src/lib/theme.svelte.ts`: theme state, OS detection, persistence
- `apps/desktop/src/lib/preferences.svelte.ts`: accent color, block shape, time fill direction and wave, date format, week start, time format (all in `localStorage`)
- `apps/desktop/src/lib/components/Toggle.svelte`: the on/off switch (water wave)
- `apps/desktop/src/lib/domain/accent.ts`: presets, custom-color adjustment, chart ramp (unit-tested)
- `apps/desktop/src/lib/components/settings/`: the accent, shape, time fill and date and time settings
- `apps/desktop/src/lib/components/Select.svelte`: the themed dropdown
- `apps/desktop/src/lib/components/settings/NotePaperPicker.svelte`: lined or plain paper
- `apps/desktop/src/lib/components/settings/DangerZone.svelte` and `DeleteDataModal.svelte`: the fold-out and the delete dialog
- `crates/irontion-core/src/data.rs`: counting and deleting by scope (`DeleteScope`, including `allNotes`), unit-tested. Commands `count_data` and `delete_data`
- `apps/desktop/src/lib/domain/datetime.ts`: date formats, clock, calendar grid (unit-tested)
- `apps/desktop/src/lib/format.svelte.ts`: display helpers that apply the user's choices
- `apps/desktop/src/app.css`: color tokens for both themes
- `apps/desktop/src/lib/charts/palette.ts`: chart colors per theme
