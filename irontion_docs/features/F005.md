# F005: Activity Templates

Ready-made sets of activities the user can add with a click: for a career, for school, for a way of managing time. Templates are **system data** (part of the app, not stored in the database). Adding one creates ordinary activities ([[F002]]) that belong to the user from then on.

> [!info] Overview
> - **12 templates**, in four groups, each in all five languages
> - Adding a template **never overlaps** what the user already has
> - A template whose names match existing activities **asks** before overwriting anything
> - Found on the Activities page (**Templates** button, and on the empty state)

## How Adding Works

1. The user picks a template and sees a **review**: every activity in it, marked **New** or **Already yours**.
2. Activities are matched **by name among siblings**, ignoring case and spaces: top level to top level, and sub-activities to the sub-activities of the matched parent. Archived activities are out of the way and don't count.
3. **New** ones are created. **Already yours** ones are **kept as they are**: never duplicated.
4. If any match, the review **asks**: each matching item has an **Overwrite** checkbox (off by default), with **Overwrite all** and **Keep all mine**.
5. One click adds everything in **one step**: all or nothing.

| You have | Template has | Result |
| -------- | ------------ | ------ |
| A | B | **A and B** |
| A | A | **Asks.** Keep A as it is (default), or overwrite it |
| A with sub-activity X | A with sub-activities X and Y | A and X kept, Y added under A |
| (an archived A) | A | A new A is created; the archived one stays archived |

### What "overwrite" means

Overwrite gives the existing activity **the template's color** (or "same as its parent" where the template says so). Nothing else changes: its name, tags and, above all, its **recorded blocks and history are never touched**. An activity is its name, so there is nothing else to replace.

## Rules and Notes

- Activity names created from a template are in the **language the app is using** at that moment, and are the user's text afterwards ("shown as typed", never translated).
- Adding a sub-activity under an existing activity that already has recorded blocks makes it a group: its blocks stay, and new blocks go to its sub-activities ([[F002]], Decisions).
- Top-level activities need a color, so every template's top level has one. Depth never exceeds 3 (the limit is 5).
- Template data is code, so a new template ships with a release. Tests check that every template is complete in all five languages, has valid colors, stays within the depth limit, and never repeats a name among siblings.

## Implementation

- Template data: `apps/desktop/src/lib/templates/data.ts`; types and helpers: `apps/desktop/src/lib/domain/templates.ts`
- Gallery, review and dialog: `apps/desktop/src/lib/components/templates/`

- The browser preview backend follows the same rules (`src/lib/api/preview.ts`)
