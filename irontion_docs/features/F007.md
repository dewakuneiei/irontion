# F007: Calendar

A month calendar of the notes from [[F006]] and of **stickers**: it shows, adds and moves notes by date, and lets the user mark a day with stickers. Just a calendar: no timer and no statistics. **The Calendar and the Notes page are two views of the same notes**, and a note's day changes **only here**: the date row of its paper on the Calendar is a button that opens the date picker (on the Notes page that row is read-only).

> [!info] Overview
> - Sidebar item **Calendar**: a month grid with previous and next month, **Today** and a month and year header
> - Follows the user's **week start** and **date format** ([[F003]]), using the shared `monthGrid` helper
> - Each day shows its **number of notes**
> - Click a day: its **side panel** lists that day's notes (many allowed) with **Add note**
> - Opening a note, or Add note, puts the **paper editor** in the panel, whose date row is the button that moves the note
> - **Stickers**: a day can carry up to 6, from 16 built-in ones or the user's own images (PNG or JPEG, cut to a square of at most 256 px). A sticker has only a name

## The Month

| Part | Behavior |
| ---- | -------- |
| Header | Month and year in the app language, previous and next month, **Today** (goes to this month and selects today) |
| Grid | 42 days (six weeks) from `monthGrid` (`domain/datetime.ts`), starting on the user's week start |
| Other months | Dimmed, still showing their counts |
| Today | The day number in an accent circle; `aria-current="date"` |
| Notes | A count pill per day (beside the day number from 640px up; below it on a phone) |
| Stickers | Up to 2 per day on the bottom row, overlapping a little, then "+N"; a phone shows the first. The cell's label names them |
| Counts | `month_counts` for the 42 visible days (the note count), refetched after any note change |

## The Day Panel

| Window | List of the day | Writing (paper) |
| ------ | --------------- | --------------- |
| 896px and up | Sticky column beside the month | In the same column (a little wider), in place of the list, with Back |
| Under 896px | Bottom sheet over the month (as on Blocks, [[F001]]) | **Takes over the page**: the month and its controls hide until Back. Never a bottom sheet |

- The list shows the day's notes as paper cards in **board order** (the order of the Notes page, pinned first); a card opens its paper.
- **Add note**: a new paper on the selected day.
- **The date row**: a button with a calendar icon that opens the shared date picker (a dialog), calling `move_note` only. Moving keeps `created_at`, sets `updated_at`, shows "Moved to <date>", and the panel follows the note to its new day (and month).
- Edit and delete work as on the Notes page: autosave, Back, Esc, Delete with Undo ([[F006]]).
- Close (×) or Esc closes the day.
- **Stickers** sit at the top of the panel, above the notes: each with a × to take it off the day, then **Add sticker** (disabled when the day has 6).

## Stickers

| Part | Behavior |
| ---- | -------- |
| Add sticker | A dialog: **Stickers** (the 16 built-in ones, named in every language) and **Your stickers**. Picking one puts it on the day and closes the dialog |
| Upload image | PNG or JPEG only (other files get "Choose a PNG or JPEG image."). Opens **New sticker**: a square frame showing exactly what the sticker will be; drag (or arrow keys) to move, the slider, the wheel or + and - to zoom, and a **Name** (starts as the file name). **Save sticker** saves it and puts it on the day |
| Size | The square is cut from the image and saved as a PNG of its own size, but never more than **256 px** (a large photo is scaled down). Transparency is kept |
| Your stickers | Kept in a library for any day. Delete (trash on hover, always shown on touch) asks first and says how many days it is on; it then comes off every day |
| Built-in | Star, Heart, Sun, Moon, Cloud, Rain, Flower, Leaf, Fire, Done, Trophy, Coffee, Book, Music, Cake, Gift. Drawn in SVG; their colors are the artwork's own, the same in both themes |
| Order | In the order added. The same sticker may go on a day twice |

## Decisions

| Decision | Why |
| -------- | --- |
| A note's date changes only from the date row on the Calendar's paper; the Notes page shows it read-only; cards on the board hide the date | One rule for dates ([[F006]], The Core Rule) |
| Writing takes over the page on narrow windows instead of a bottom sheet | A sheet is too small to write on, and the keyboard would cover it |
| Counts come from the backend for the 42 visible days | The core owns the grouping; dimmed days are right too |
| After a move, the panel follows the note | Back then shows the day the note is on now |
| The day's list reads the shared `notes` store | No second fetch; an edit shows on both pages at once |
| Count pill, not dots | Dots don't scale to many notes |
| Stickers are their own tables (`stickers`, `day_stickers`), not part of notes | A sticker marks a day, not a note; deleting notes never touches them |
| Built-in stickers are system data in the frontend; the database stores only their id (`STICKER_PRESETS` in core and `domain/stickers.ts`) | Like templates: art and names can change without a migration, and they are translated |
| The image is cropped and scaled in the window; the core only checks it (a square PNG, 1-256 px, at most 512 KB) and stores it | Canvas does the image work; Rust stays free of an image library and still refuses anything else |
| Stored as a PNG blob, sent as a `data:image/png;base64,...` URL | One shape in both directions, ready for an `<img>` |
| At most 6 per day, checked in core (`tooManyStickers`) | A cell has room for a few; more would only be "+N" |
| Deleting an own sticker removes it from every day (foreign-key cascade), after a confirmation with the count | A missing image would leave a hole on those days |

## Implementation

- Page: `apps/desktop/src/routes/calendar/+page.svelte`
- Components: `apps/desktop/src/lib/components/calendar/` (`MonthGrid`, `DayPanel`); the paper is `components/notes/NotePaper.svelte` ([[F006]])
- Pure logic: `apps/desktop/src/lib/domain/calendar.ts` (`visibleRange`, `countsByDate`, `stepMonth`, `relativeDay`), unit-tested
- Data: `notes.monthCounts()` and `notes.move()` in `stores/notes.svelte.ts`, backed by `irontion_core::notes::month_counts` and `move_note`
- Stickers: migration `crates/irontion-core/migrations/009_stickers.sql`; rules in `crates/irontion-core/src/stickers.rs` (`list`, `create`, `delete`, `on_days`, `add_to_day`, `remove_from_day`), unit-tested; commands `list_stickers`, `create_sticker`, `delete_sticker`, `day_stickers`, `add_day_sticker`, `remove_day_sticker`
- Sticker logic: `apps/desktop/src/lib/domain/stickers.ts` (presets, PNG size check, crop math), unit-tested; art in `lib/stickers/art.ts`; store `stores/stickers.svelte.ts`; components `components/stickers/` (`DayStickers`, `StickerPickerModal`, `StickerCropper`, `StickerImage`)
